Live in MediaCockpit

Cockpit AI

A context-aware assistant inside an enterprise product information management platform. It connects catalogue data, documents, and portal actions to answer with evidence and stage changes for review.

  • 23 documented operations across six tool families, built inside an existing Java platform.
  • Best retrieval result 0.9067 nDCG@10 with an optional cross-encoder; the reranker stayed opt-in for latency.
  • Full-agent QA: 23 of 25 requests completed; mean faithfulness 0.8338 across eligible answers.
  • RAG
  • LangGraph4j
  • Evaluation

Competition · 11th of 50+

Presto

Product retrieval where most training positives had no exact catalogue match. Hybrid retrieval, rank fusion, and cross-encoder reranking placed 11th on the final leaderboard.

  • 0.62773 nDCG@10 across 29,014 queries and 107,041 products.
  • 90.8% of training positives had no exact match; source is not public.
  • Python
  • Retrieval
  • Ranking

Research · CIC-DDoS2019

DDoS Detection

A flow-feature transformer for 12-class DDoS detection, evaluated class by class instead of hiding weak classes behind aggregate accuracy.

  • 95.26% accuracy and 0.95 macro-F1 on a balanced 14,400-flow holdout.
  • NetBIOS recall was 0.65; the confusion matrix is public.
  • PyTorch
  • Transformers
  • Security
