Jan 2026 — Present

Bertsch Innovation GmbH · MediaCockpit

AI Engineering Intern

Work on the assistant layer inside MediaCockpit, an existing enterprise PIM. The role spans context handling, typed tool contracts, retrieval, interface integration, evaluation, and the MC15 migration.

  • Documented 23 assistant operations across six tool families, including search, page context, navigation, data quality, documents, and diagnostics.
  • Built cross-collection retrieval over node and attribute views, then measured fusion and optional cross-encoder ranking. Best NDCG@10 was 0.9067; the reranker’s mean CPU latency was 26.3 seconds, so it stayed opt-in.
  • Ran full-agent QA on 25 questions: 23 completed, mean faithfulness 0.8338 across eligible answers. The evaluation is a development set, not production A/B evidence.
  • Migrated the assistant to MC15’s API and page-context model; MC14 metrics are not presented as MC15 results.

Jul 2025 — Sep 2025

ESPRIT Research Lab

Research Intern

Worked on transformer-based network intrusion detection: preprocessing, a 12-class model, class-level evaluation, and interpretation of the model’s behaviour across traffic families.

  • Built a flow-feature transformer with four feature groups: temporal, spatial, protocol, and statistical.
  • Reached 95.26% accuracy and 0.95 macro-F1 on a balanced 14,400-flow holdout; NetBIOS recall was 0.65, which the aggregate score hides.
  • Used attention inspection and integrated gradients; no SHAP or adversarial-robustness results are claimed.
  • Published the model, confusion matrix, and interpretation code on GitHub.
